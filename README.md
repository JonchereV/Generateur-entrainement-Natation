# 🏊 Générateur d'entraînement de natation

Application web légère qui génère des séances de natation en piscine, structurées comme dans un club, et adaptées au niveau du nageur.

👉 **Démo en ligne** : https://jonchereV.github.io/Generateur-entrainement-Natation/

## Fonctionnalités

- Génération de séances en piscine
- Structure type club :
  - échauffement
  - technique
  - volume
  - intensité
  - retour au calme
- Pourcentages et charges adaptés au niveau du nageur
- Export PDF synthétique de la séance
- Fonctionne dans le navigateur, sans installation ni serveur (fichier HTML unique)

## Utilisation

1. Ouvrir la page de démo (ou `index.html` dans un navigateur).
2. Choisir [niveau, durée / distance, bassin 25 m ou 50 m, etc.].
3. Cliquer sur **Générer** pour obtenir la séance.
4. Exporter la séance en PDF pour l'imprimer ou l'emporter au bord du bassin.

## Installation locale

```bash
git clone [https://github.com/JonchereV/Generateur-entrainement-Natation.git](https://github.com/JonchereV/Generateur-entrainement-Natation.git)
cd Generateur-entrainement-Natation
```

Ouvrez ensuite `index.html` dans votre navigateur.
